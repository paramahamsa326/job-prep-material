# ServiceNow Project Evidence Catalog

Last updated: 2026-08-01

Purpose: private source material for resume tailoring. This catalog may be incomplete and should be expanded as additional projects are recalled.

## Usage rules

- Do not automatically list project names in resumes.
- Prefer generalized components, platform capabilities, and business outcomes.
- A public ServiceNow product name may be used when it materially improves alignment with a ServiceNow job description and the user approves it.
- Do not imply ownership of an entire product. Describe the specific components, services, workflows, integrations, or features personally designed or developed.
- Attach technologies, scale, metrics, and personal contributions to each project as they become available.
