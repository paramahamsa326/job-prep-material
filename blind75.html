1. Two Sum (Array)

Question: Find indices of two numbers that add up to a target.

Approach:

Use a HashMap to store values and their index. Check if target - current_value exists.

Time: O(N) | Space: O(N)
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        if (map.containsKey(target - nums[i])) return new int[]{map.get(target - nums[i]), i};
        map.put(nums[i], i);
    }
    return new int[]{};
}
2. Best Time to Buy and Sell Stock (Array)

Question: Maximize profit from buying on one day and selling on a future day.

Approach:

Track min price so far and update max profit at each step.

Time: O(N) | Space: O(1)
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE, maxProfit = 0;
    for (int price : prices) {
        minPrice = Math.min(minPrice, price);
        maxProfit = Math.max(maxProfit, price - minPrice);
    }
    return maxProfit;
}
3. Contains Duplicate (Array)

Question: Check if any value appears at least twice in the array.

Approach:

Add elements to a HashSet. Return true if add fails.

Time: O(N) | Space: O(N)
public boolean containsDuplicate(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int num : nums) if (!set.add(num)) return true;
    return false;
}
4. Product of Array Except Self (Array)

Question: Return output array where output[i] is product of all elements except nums[i].

Approach:

Compute prefix products, then multiply by postfix products from right to left.

Time: O(N) | Space: O(1) auxiliary
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] res = new int[n];
    res[0] = 1;
    for (int i = 1; i < n; i++) res[i] = res[i - 1] * nums[i - 1];
    int right = 1;
    for (int i = n - 1; i >= 0; i--) {
        res[i] *= right;
        right *= nums[i];
    }
    return res;
}
5. Maximum Subarray (Array / DP)

Question: Find contiguous subarray with largest sum (Kadane's algorithm).

Approach:

Track current running sum. Reset to current element if running sum goes negative.

Time: O(N) | Space: O(1)
public int maxSubArray(int[] nums) {
    int max = nums[0], curr = nums[0];
    for (int i = 1; i < nums.length; i++) {
        curr = Math.max(nums[i], curr + nums[i]);
        max = Math.max(max, curr);
    }
    return max;
}
6. Maximum Product Subarray (Array / DP)

Question: Find contiguous subarray that has the largest product.

Approach:

Maintain max and min products seen so far; swap them when encountering a negative number.

Time: O(N) | Space: O(1)
public int maxProduct(int[] nums) {
    int res = nums[0], max = nums[0], min = nums[0];
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] < 0) { int tmp = max; max = min; min = tmp; }
        max = Math.max(nums[i], max * nums[i]);
        min = Math.min(nums[i], min * nums[i]);
        res = Math.max(res, max);
    }
    return res;
}
7. Find Minimum in Rotated Sorted Array (Binary Search)

Question: Find the minimum element in a sorted array that was rotated.

Approach:

Binary search: if mid > right, min is in the right half; otherwise, it's in the left half.

Time: O(log N) | Space: O(1)
public int findMin(int[] nums) {
    int l = 0, r = nums.length - 1;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] > nums[r]) l = mid + 1;
        else r = mid;
    }
    return nums[l];
}
8. Search in Rotated Sorted Array (Binary Search)

Question: Search for target in rotated sorted array, return index or -1.

Approach:

Binary search: determine which half is sorted, then check if target lies within that half.

Time: O(log N) | Space: O(1)
public int search(int[] nums, int target) {
    int l = 0, r = nums.length - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;
        if (nums[l] <= nums[mid]) {
            if (target >= nums[l] && target < nums[mid]) r = mid - 1;
            else l = mid + 1;
        } else {
            if (target > nums[mid] && target <= nums[r]) l = mid + 1;
            else r = mid - 1;
        }
    }
    return -1;
}
9. 3Sum (Array / Two Pointers)

Question: Find all unique triplets [a, b, c] that sum to 0.

Approach:

Sort array. Fix first element and use two pointers for remainder; skip duplicates.

Time: O(N²) | Space: O(1) auxiliary
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res = new ArrayList<>();
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        int l = i + 1, r = nums.length - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                while (l < r && nums[l] == nums[l + 1]) l++;
                while (l < r && nums[r] == nums[r - 1]) r--;
                l++; r--;
            } else if (sum < 0) l++;
            else r--;
        }
    }
    return res;
}
10. Container With Most Water (Two Pointers)

Question: Find two lines that form a container storing max water.

Approach:

Start with outer boundaries. Calculate area and advance the pointer with smaller height.

Time: O(N) | Space: O(1)
public int maxArea(int[] height) {
    int l = 0, r = height.length - 1, max = 0;
    while (l < r) {
        max = Math.max(max, Math.min(height[l], height[r]) * (r - l));
        if (height[l] < height[r]) l++;
        else r--;
    }
    return max;
}
11. Sum of Two Integers (Binary)

Question: Calculate sum of two integers without using + or - operators.

Approach:

Use XOR for bit addition without carry and AND shifted left for carry iteratively.

Time: O(1) | Space: O(1)
public int getSum(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1;
        a = a ^ b;
        b = carry;
    }
    return a;
}
12. Number of 1 Bits (Binary)

Question: Return number of set bits ('1's) in an integer.

Approach:

Brian Kernighan's algorithm: clear lowest set bit using n & (n - 1) repeatedly.

Time: O(1) | Space: O(1)
public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1);
        count++;
    }
    return count;
}
13. Counting Bits (Binary / DP)

Question: Return array where ans[i] is number of 1 bits in i for 0 <= i <= n.

Approach:

Use dynamic programming: dp[i] = dp[i >> 1] + (i & 1).

Time: O(N) | Space: O(N)
public int[] countBits(int n) {
    int[] dp = new int[n + 1];
    for (int i = 1; i <= n; i++) dp[i] = dp[i >> 1] + (i & 1);
    return dp;
}
14. Missing Number (Binary / Math)

Question: Find the only missing number in array containing 0 to n.

Approach:

XOR all indices and elements. Duplicate values cancel out, leaving the missing number.

Time: O(N) | Space: O(1)
public int missingNumber(int[] nums) {
    int xor = nums.length;
    for (int i = 0; i < nums.length; i++) xor ^= i ^ nums[i];
    return xor;
}
15. Reverse Bits (Binary)

Question: Reverse bits of a 32-bit unsigned integer.

Approach:

Iterate 32 times: shift result left, append last bit of input, shift input right.

Time: O(1) | Space: O(1)
public int reverseBits(int n) {
    int res = 0;
    for (int i = 0; i < 32; i++) {
        res = (res << 1) | (n & 1);
        n >>>= 1;
    }
    return res;
}
16. Climbing Stairs (DP)

Question: Count distinct ways to climb n stairs taking 1 or 2 steps.

Approach:

Fibonacci DP sequence: dp[i] = dp[i-1] + dp[i-2], optimized to two variables.

Time: O(N) | Space: O(1)
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int sum = a + b; a = b; b = sum;
    }
    return b;
}
17. Coin Change (DP)

Question: Fewest coins needed to make up a given amount.

Approach:

Bottom-up DP: dp[i] represents min coins needed to make amount i.

Time: O(amount * coins) | Space: O(amount)
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (i - coin >= 0) dp[i] = Math.min(dp[i], 1 + dp[i - coin]);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
18. Longest Increasing Subsequence (DP / Binary Search)

Question: Find length of longest strictly increasing subsequence.

Approach:

Maintain tail array. Use binary search (Arrays.binarySearch) to update or append values.

Time: O(N log N) | Space: O(N)
public int lengthOfLIS(int[] nums) {
    int[] tails = new int[nums.length];
    int size = 0;
    for (int x : nums) {
        int i = 0, j = size;
        while (i != j) {
            int m = (i + j) / 2;
            if (tails[m] < x) i = m + 1;
            else j = m;
        }
        tails[i] = x;
        if (i == size) size++;
    }
    return size;
}
19. Longest Common Subsequence (DP)

Question: Return length of longest common subsequence of two strings.

Approach:

2D DP table: if chars match, 1 + dp[i+1][j+1]; else max(dp[i+1][j], dp[i][j+1]).

Time: O(M * N) | Space: O(M * N)
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = m - 1; i >= 0; i--) {
        for (int j = n - 1; j >= 0; j--) {
            if (text1.charAt(i) == text2.charAt(j)) dp[i][j] = 1 + dp[i + 1][j + 1];
            else dp[i][j] = Math.max(dp[i + 1][j], dp[i][j + 1]);
        }
    }
    return dp[0][0];
}
20. Word Break (DP)

Question: Check if string can be segmented into dictionary words.

Approach:

DP: dp[i] is true if s[0...i] can be formed using dictionary words.

Time: O(N²) | Space: O(N)
public boolean wordBreak(String s, List<String> wordDict) {
    Set<String> set = new HashSet<>(wordDict);
    boolean[] dp = new boolean[s.length() + 1];
    dp[0] = true;
    for (int i = 1; i <= s.length(); i++) {
        for (int j = 0; j < i; j++) {
            if (dp[j] && set.contains(s.substring(j, i))) {
                dp[i] = true;
                break;
            }
        }
    }
    return dp[s.length()];
}
21. Combination Sum (Backtracking)

Question: Find all unique combinations summing to target (repetition allowed).

Approach:

Backtracking: recursively choose candidates, reducing target until target == 0.

Time: O(2^T) | Space: O(T) target recursive depth
public List<List<Integer>> combinationSum(int[] candidates, int target) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(res, new ArrayList<>(), candidates, target, 0);
    return res;
}
private void backtrack(List<List<Integer>> res, List<Integer> temp, int[] nums, int remain, int start) {
    if (remain < 0) return;
    if (remain == 0) res.add(new ArrayList<>(temp));
    else {
        for (int i = start; i < nums.length; i++) {
            temp.add(nums[i]);
            backtrack(res, temp, nums, remain - nums[i], i);
            temp.remove(temp.size() - 1);
        }
    }
}
22. House Robber (DP)

Question: Maximize money stolen without robbing adjacent houses.

Approach:

DP relation: rob = max(prev1, prev2 + current_house).

Time: O(N) | Space: O(1)
public int rob(int[] nums) {
    int prev1 = 0, prev2 = 0;
    for (int num : nums) {
        int tmp = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = tmp;
    }
    return prev1;
}
23. House Robber II (DP)

Question: Maximize money stolen from houses arranged in a circle.

Approach:

Run standard House Robber logic twice: on [0, N-2] and on [1, N-1], taking the max.

Time: O(N) | Space: O(1)
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    return Math.max(robHelper(nums, 0, nums.length - 2), robHelper(nums, 1, nums.length - 1));
}
private int robHelper(int[] nums, int start, int end) {
    int prev1 = 0, prev2 = 0;
    for (int i = start; i <= end; i++) {
        int tmp = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1; prev1 = tmp;
    }
    return prev1;
}
24. Decode Ways (DP)

Question: Count total number of valid decodings for a numeric string ('A'=1...'Z'=26).

Approach:

DP: check if single-digit and double-digit slices form valid codes between 1 and 26.

Time: O(N) | Space: O(N)
public int numDecodings(String s) {
    int n = s.length();
    int[] dp = new int[n + 1];
    dp[n] = 1;
    for (int i = n - 1; i >= 0; i--) {
        if (s.charAt(i) != '0') {
            dp[i] += dp[i + 1];
            if (i + 1 < n && Integer.parseInt(s.substring(i, i + 2)) <= 26) {
                dp[i] += dp[i + 2];
            }
        }
    }
    return dp[0];
}
25. Unique Paths (DP)

Question: Count unique paths from top-left to bottom-right of m x n grid.

Approach:

2D DP: dp[r][c] = dp[r+1][c] + dp[r][c+1], optimized to 1D array.

Time: O(M * N) | Space: O(N)
public int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) dp[j] += dp[j - 1];
    }
    return dp[n - 1];
}
26. Jump Game (Dynamic Programming / Greedy)

Question: Determine if you can reach the last index starting from index 0.

Approach:

Track maximum reachable index greedily while iterating through the array.

Time: O(N) | Space: O(1)
public boolean canJump(int[] nums) {
    int maxReach = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > maxReach) return false;
        maxReach = Math.max(maxReach, i + nums[i]);
    }
    return true;
}
27. Clone Graph (Graph / DFS)

Question: Return a deep copy of a connected undirected graph.

Approach:

Use DFS with a HashMap to track original nodes mapped to their cloned counterparts.

Time: O(V + E) | Space: O(V)
public Node cloneGraph(Node node) {
    if (node == null) return null;
    Map<Node, Node> map = new HashMap<>();
    return dfs(node, map);
}
private Node dfs(Node node, Map<Node, Node> map) {
    if (map.containsKey(node)) return map.get(node);
    Node copy = new Node(node.val);
    map.put(node, copy);
    for (Node neighbor : node.neighbors) {
        copy.neighbors.add(dfs(neighbor, map));
    }
    return copy;
}
28. Course Schedule (Graph / Topological Sort)

Question: Determine if you can finish all courses given prerequisite pairs.

Approach:

Detect cycle using Kahn's algorithm (indegree array + BFS queue).

Time: O(V + E) | Space: O(V + E)
public boolean canFinish(int numCourses, int[][] prerequisites) {
    List<List<Integer>> adj = new ArrayList<>();
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());
    for (int[] p : prerequisites) {
        adj.get(p[1]).add(p[0]);
        indegree[p[0]]++;
    }
    Queue<Integer> q = new LinkedList<>();
    for (int i = 0; i < numCourses; i++) if (indegree[i] == 0) q.add(i);
    int count = 0;
    while (!q.isEmpty()) {
        int curr = q.poll();
        count++;
        for (int next : adj.get(curr)) {
            if (--indegree[next] == 0) q.add(next);
        }
    }
    return count == numCourses;
}
29. Pacific Atlantic Water Flow (Graph / DFS)

Question: Find grid coordinates where water can flow to both Pacific and Atlantic oceans.

Approach:

Run DFS inland from Pacific borders and Atlantic borders separately; find intersection.

Time: O(M * N) | Space: O(M * N)
public List<List<Integer>> pacificAtlantic(int[][] heights) {
    List<List<Integer>> res = new ArrayList<>();
    int m = heights.length, n = heights[0].length;
    boolean[][] pac = new boolean[m][n], atl = new boolean[m][n];
    for (int i = 0; i < m; i++) {
        dfs(heights, pac, i, 0, heights[i][0]);
        dfs(heights, atl, i, n - 1, heights[i][n - 1]);
    }
    for (int j = 0; j < n; j++) {
        dfs(heights, pac, 0, j, heights[0][j]);
        dfs(heights, atl, m - 1, j, heights[m - 1][j]);
    }
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (pac[i][j] && atl[i][j]) res.add(Arrays.asList(i, j));
        }
    }
    return res;
}
private void dfs(int[][] h, boolean[][] vis, int r, int c, int prevH) {
    if (r < 0 || c < 0 || r >= h.length || c >= h[0].length || vis[r][c] || h[r][c] < prevH) return;
    vis[r][c] = true;
    dfs(h, vis, r + 1, c, h[r][c]); dfs(h, vis, r - 1, c, h[r][c]);
    dfs(h, vis, r, c + 1, h[r][c]); dfs(h, vis, r, c - 1, h[r][c]);
}
30. Number of Islands (Graph / DFS)

Question: Count total 2D islands ('1' land surrounded by '0' water).

Approach:

Traverse grid. When encountering '1', increment island count and run DFS to sink land to '0'.

Time: O(M * N) | Space: O(M * N)
public int numIslands(char[][] grid) {
    int count = 0;
    for (int r = 0; r < grid.length; r++) {
        for (int c = 0; c < grid[0].length; c++) {
            if (grid[r][c] == '1') {
                count++;
                dfs(grid, r, c);
            }
        }
    }
    return count;
}
private void dfs(char[][] g, int r, int c) {
    if (r < 0 || c < 0 || r >= g.length || c >= g[0].length || g[r][c] == '0') return;
    g[r][c] = '0';
    dfs(g, r + 1, c); dfs(g, r - 1, c); dfs(g, r, c + 1); dfs(g, r, c - 1);
}
31. Graph Valid Tree (Graph / Union Find)

Question: Check if an undirected graph forms a valid tree.

Approach:

Graph is a valid tree if it has exactly N - 1 edges and no cycles (Union-Find structure).

Time: O(N * α(N)) | Space: O(N)
public boolean validTree(int n, int[][] edges) {
    if (edges.length != n - 1) return false;
    int[] parent = new int[n];
    for (int i = 0; i < n; i++) parent[i] = i;
    for (int[] e : edges) {
        int root1 = find(parent, e[0]);
        int root2 = find(parent, e[1]);
        if (root1 == root2) return false;
        parent[root1] = root2;
    }
    return true;
}
private int find(int[] parent, int i) {
    if (parent[i] == i) return i;
    return parent[i] = find(parent, parent[i]);
}
32. Number of Connected Components in Undirected Graph (Graph)

Question: Find total connected components in an undirected graph.

Approach:

Use Union-Find. Start with N components and decrement upon unioning disjoint sets.

Time: O(E * α(V)) | Space: O(V)
public int countComponents(int n, int[][] edges) {
    int[] parent = new int[n];
    for (int i = 0; i < n; i++) parent[i] = i;
    int components = n;
    for (int[] e : edges) {
        int r1 = find(parent, e[0]), r2 = find(parent, e[1]);
        if (r1 != r2) {
            parent[r1] = r2;
            components--;
        }
    }
    return components;
}
private int find(int[] parent, int i) {
    if (parent[i] == i) return i;
    return parent[i] = find(parent, parent[i]);
}
33. Insert Interval (Intervals)

Question: Insert a new interval into sorted non-overlapping intervals and merge if needed.

Approach:

Add non-overlapping intervals before, merge overlapping intervals, then add remainder.

Time: O(N) | Space: O(N)
public int[][] insert(int[][] intervals, int[] newInterval) {
    List<int[]> res = new ArrayList<>();
    int i = 0, n = intervals.length;
    while (i < n && intervals[i][1] < newInterval[0]) res.add(intervals[i++]);
    while (i < n && intervals[i][0] <= newInterval[1]) {
        newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
        newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
        i++;
    }
    res.add(newInterval);
    while (i < n) res.add(intervals[i++]);
    return res.toArray(new int[res.size()][]);
}
34. Merge Intervals (Intervals)

Question: Merge all overlapping intervals in an array.

Approach:

Sort intervals by start. Compare current start time against previous interval's end time.

Time: O(N log N) | Space: O(N)
public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    List<int[]> res = new ArrayList<>();
    int[] curr = intervals[0];
    res.add(curr);
    for (int[] next : intervals) {
        if (curr[1] >= next[0]) curr[1] = Math.max(curr[1], next[1]);
        else { curr = next; res.add(curr); }
    }
    return res.toArray(new int[res.size()][]);
}
35. Non-overlapping Intervals (Intervals / Greedy)

Question: Minimum intervals to remove to make remaining intervals non-overlapping.

Approach:

Greedy choice: sort intervals by end times and remove intervals that overlap.

Time: O(N log N) | Space: O(1) auxiliary
public int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));
    int count = 0, prevEnd = intervals[0][1];
    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] < prevEnd) count++;
        else prevEnd = intervals[i][1];
    }
    return count;
}
36. Meeting Rooms (Intervals)

Approach:

Sort intervals by start time; return false if any meeting starts before previous one ends.

Time: O(N log N) | Space: O(1) auxiliary

    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

37. Meeting Rooms II (Intervals / Heap)

Question: Find minimum number of conference rooms required.

Approach:

Sort start and end times separately; use two pointers to count active overlapping meetings.

Time: O(N log N) | Space: O(N)
public int minMeetingRooms(int[][] intervals) {
    int n = intervals.length;
    int[] starts = new int[n], ends = new int[n];
    for (int i = 0; i < n; i++) {
        starts[i] = intervals[i][0];
        ends[i] = intervals[i][1];
    }
    Arrays.sort(starts); Arrays.sort(ends);
    int rooms = 0, endIdx = 0;
    for (int i = 0; i < n; i++) {
        if (starts[i] < ends[endIdx]) rooms++;
        else endIdx++;
    }
    return rooms;
}
38. Reverse Linked List (Linked List)

Question: Reverse a singly linked list.

Approach:

Iterate through list, re-pointing curr.next to prev pointer.

Time: O(N) | Space: O(1)
public ListNode reverseList(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}
39. Linked List Cycle (Linked List)

Question: Detect if a linked list contains a cycle.

Approach:

Floyd's Tortoise and Hare algorithm: use slow and fast pointers.

Time: O(N) | Space: O(1)
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }

}
40. Merge Two Sorted Lists (Linked List)

Question: Splice together two sorted linked lists into one sorted list.

Approach:

Use dummy node to continuously attach smaller head node from list1 or list2.

Time: O(N + M) | Space: O(1)
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), curr = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val < l2.val) { curr.next = l1; l1 = l1.next; }
        else { curr.next = l2; l2 = l2.next; }
        curr = curr.next;
    }
    curr.next = (l1 != null) ? l1 : l2;
    return dummy.next;
}
41. Merge k Sorted Lists (Linked List / Heap)

Question: Merge k sorted linked lists into one sorted linked list.

Approach:

Use a PriorityQueue (Min-Heap) storing the head node of each of the k lists.

Time: O(N log k) | Space: O(k)
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode node : lists) if (node != null) pq.add(node);
    ListNode dummy = new ListNode(0), curr = dummy;
    while (!pq.isEmpty()) {
        ListNode top = pq.poll();
        curr.next = top;
        curr = curr.next;
        if (top.next != null) pq.add(top.next);
    }
    return dummy.next;
}
42. Remove Nth Node From End of List (Linked List)

Question: Remove the nth node from the end of a linked list.

Approach:

Use two pointers offset by n nodes. Advance both until fast reaches end.

Time: O(N) | Space: O(1)
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i <= n; i++) fast = fast.next;
    while (fast != null) {
        slow = slow.next;
        fast = fast.next;
    }
    slow.next = slow.next.next;
    return dummy.next;
}
43. Reorder List (Linked List)

Question: Reorder list to L0 → Ln → L1 → Ln-1 → L2 → Ln-2...

Approach:

1. Find middle node. 2. Reverse second half. 3. Merge two halves alternatingly.

Time: O(N) | Space: O(1)
public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode prev = null, curr = slow.next;
    slow.next = null;
    while (curr != null) {
        ListNode tmp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = tmp;
    }
    ListNode first = head, second = prev;
    while (second != null) {
        ListNode tmp1 = first.next, tmp2 = second.next;
        first.next = second;
        second.next = tmp1;
        first = tmp1;
        second = tmp2;
    }
}
44. Rotate Image (Matrix)

Question: Rotate an n x n 2D matrix 90 degrees clockwise in-place.

Approach:

Transpose the matrix (swap matrix[i][j] with matrix[j][i]), then reverse each row.

Time: O(N²) | Space: O(1)
public void rotate(int[][] matrix) {
    int n = matrix.length;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = tmp;
        }
    }
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n / 2; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[i][n - 1 - j];
            matrix[i][n - 1 - j] = tmp;
        }
    }
}
45. Spiral Matrix (Matrix)

Question: Return all elements of m x n matrix in spiral order.

Approach:

Maintain boundaries (top, bottom, left, right) and shrink them after completing each side.

Time: O(M * N) | Space: O(1) auxiliary
public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> res = new ArrayList<>();
    int top = 0, bottom = matrix.length - 1, left = 0, right = matrix[0].length - 1;
    while (top <= bottom && left <= right) {
        for (int i = left; i <= right; i++) res.add(matrix[top][i]);
        top++;
        for (int i = top; i <= bottom; i++) res.add(matrix[i][right]);
        right--;
        if (top <= bottom) {
            for (int i = right; i >= left; i--) res.add(matrix[bottom][i]);
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--) res.add(matrix[i][left]);
            left++;
        }
    }
    return res;
}
46. Set Matrix Zeroes (Matrix)

Question: If an element is 0, set its entire row and column to 0 in-place.

Approach:

Use the first row and first column as markers to keep track of zeros.

Time: O(M * N) | Space: O(1)
public void setZeroes(int[][] matrix) {
    boolean firstRow = false, firstCol = false;
    int m = matrix.length, n = matrix[0].length;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstCol = true;
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRow = true;
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][j] == 0) { matrix[i][0] = 0; matrix[0][j] = 0; }
        }
    }
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;
        }
    }
    if (firstCol) for (int i = 0; i < m; i++) matrix[i][0] = 0;
    if (firstRow) for (int j = 0; j < n; j++) matrix[0][j] = 0;
}
47. Word Search (Matrix / Backtracking)

Question: Check if word exists in 2D grid of characters.

Approach:

Run DFS with backtracking starting from each grid cell matching word[0].

Time: O(N * 3^L) | Space: O(L) call stack
public boolean exist(char[][] board, String word) {
    for (int r = 0; r < board.length; r++) {
        for (int c = 0; c < board[0].length; c++) {
            if (dfs(board, word, r, c, 0)) return true;
        }
    }
    return false;
}
private boolean dfs(char[][] b, String w, int r, int c, int i) {
    if (i == w.length()) return true;
    if (r < 0 || c < 0 || r >= b.length || c >= b[0].length || b[r][c] != w.charAt(i)) return false;
    char tmp = b[r][c];
    b[r][c] = '#';
    boolean found = dfs(b, w, r + 1, c, i + 1) || dfs(b, w, r - 1, c, i + 1) ||
                    dfs(b, w, r, c + 1, i + 1) || dfs(b, w, r, c - 1, i + 1);
    b[r][c] = tmp;
    return found;
}
48. Longest Substring Without Repeating Characters (String / Sliding Window)

Question: Find length of longest substring without duplicate characters.

Approach:

Sliding window: store last seen indices of characters in a Map to adjust left boundary.

Time: O(N) | Space: O(N)
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> map = new HashMap<>();
    int max = 0, l = 0;
    for (int r = 0; r < s.length(); r++) {
        char c = s.charAt(r);
        if (map.containsKey(c)) l = Math.max(l, map.get(c) + 1);
        map.put(c, r);
        max = Math.max(max, r - l + 1);
    }
    return max;
}
49. Longest Repeating Character Replacement (String / Sliding Window)

Question: Max length of substring with same letters after replacing at most k characters.

Approach:

Sliding window: expand window right; if (window_len - max_frequency) > k, shrink left.

Time: O(N) | Space: O(1)
public int characterReplacement(String s, int k) {
    int[] count = new int[26];
    int maxCount = 0, l = 0, maxLen = 0;
    for (int r = 0; r < s.length(); r++) {
        maxCount = Math.max(maxCount, ++count[s.charAt(r) - 'A']);
        while ((r - l + 1) - maxCount > k) {
            count[s.charAt(l) - 'A']--;
            l++;
        }
        maxLen = Math.max(maxLen, r - l + 1);
    }
    return maxLen;
}
50. Minimum Window Substring (String / Sliding Window)

Question: Find minimum window in s containing all characters of t.

Approach:

Sliding window using frequency array and a count variable for required matches.

Time: O(N) | Space: O(1)
public String minWindow(String s, String t) {
    int[] map = new int[128];
    for (char c : t.toCharArray()) map[c]++;
    int count = t.length(), l = 0, r = 0, minLen = Integer.MAX_VALUE, start = 0;
    while (r < s.length()) {
        if (map[s.charAt(r++)]-- > 0) count--;
        while (count == 0) {
            if (r - l < minLen) { minLen = r - l; start = l; }
            if (map[s.charAt(l++)]++ == 0) count++;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}

54. Valid Palindrome (String / Two Pointers)

Question: Check if a string is a palindrome, ignoring non-alphanumeric characters and case.

Approach:

Two pointers moving inwards, skipping non-alphanumeric characters.

Time: O(N) | Space: O(1)
public boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
        while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
        if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r))) return false;
        l++; r--;
    }

}
55. Longest Palindromic Substring (String / Two Pointers)

Question: Find the longest palindromic substring in s.

Approach:

Expand around center for both odd and even length palindromes at each index.

Time: O(N²) | Space: O(1)
public String longestPalindrome(String s) {
    int start = 0, end = 0;
    for (int i = 0; i < s.length(); i++) {
        int len1 = expand(s, i, i);
        int len2 = expand(s, i, i + 1);
        int len = Math.max(len1, len2);
        if (len > end - start) {
            start = i - (len - 1) / 2;
            end = i + len / 2;
        }
    }
    return s.substring(start, end + 1);
}
private int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return r - l - 1;
}
56. Palindromic Substrings (String / Two Pointers)

Approach:

Expand around center for every possible center (2N - 1 total centers) and increment count.

Time: O(N²) | Space: O(1)
public int countSubstrings(String s) {
    int count = 0;
    for (int i = 0; i < s.length(); i++) {
        count += expand(s, i, i);
        count += expand(s, i, i + 1);
    }

}
private int expand(String s, int l, int r) {
    int res = 0;
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        res++; l--; r++;
    }
    return res;
}

BFS using Queue; process nodes level by level using current queue size.

public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();

        }

    }

}

69. Implement Trie (Prefix Tree) (Trie)

Question: Implement insert, search, and startsWith methods for a Trie.

class Trie {

        Node[] children = new Node[26];
        boolean isEnd;

        Node curr = root;
        for (char c : word.toCharArray()) {
            if (curr.children[c - 'a'] == null) curr.children[c - 'a'] = new Node();
            curr = curr.children[c - 'a'];
        }

        }
        return curr;
    }
}
70. Design Add and Search Words Data Structure (Trie / Backtracking)

Question: Design data structure supporting adding words and searching with '.' wildcard.

Approach:

Use Trie. When encountering '.', recursively search across all existing non-null children.

Time: O(L) insert, O(26^L) worst case search | Space: O(N * L)
class WordDictionary {
    class Node {
        Node[] children = new Node[26];
        boolean isEnd;
    }
    private Node root = new Node();

    public void addWord(String word) {
        Node curr = root;
        for (char c : word.toCharArray()) {
            if (curr.children[c - 'a'] == null) curr.children[c - 'a'] = new Node();
            curr = curr.children[c - 'a'];
        }
        curr.isEnd = true;
    }

        return match(word, 0, root);

    private boolean match(String w, int idx, Node node) {

            for (Node child : node.children) {
                if (child != null && match(w, idx + 1, child)) return true;
            }
            return false;
        } else {
            return match(w, idx + 1, node.children[c - 'a']);
        }
    }
}

Approach:

Build Trie from dictionary words. DFS from grid cells, traversing grid and Trie concurrently.

Time: O(M * N * 3^L) | Space: O(K * L) Trie size
public List<String> findWords(char[][] board, String[] words) {
    List<String> res = new ArrayList<>();
    TrieNode root = buildTrie(words);
    for (int r = 0; r < board.length; r++) {
        for (int c = 0; c < board[0].length; c++) dfs(board, r, c, root, res);
    }
    return res;
}
private void dfs(char[][] b, int r, int c, TrieNode p, List<String> res) {
    char ch = b[r][c];
    if (ch == '#' || p.next[ch - 'a'] == null) return;
    p = p.next[ch - 'a'];
    if (p.word != null) {
        res.add(p.word);
        p.word = null; // Avoid duplicates
    }
    b[r][c] = '#';
    if (r > 0) dfs(b, r - 1, c, p, res);
    if (c > 0) dfs(b, r, c - 1, p, res);
    if (r < b.length - 1) dfs(b, r + 1, c, p, res);
    if (c < b[0].length - 1) dfs(b, r, c + 1, p, res);
    b[r][c] = ch;
}
class TrieNode {
    TrieNode[] next = new TrieNode[26];
    String word;
}
private TrieNode buildTrie(String[] words) {
    TrieNode root = new TrieNode();
    for (String w : words) {
        TrieNode p = root;
        for (char c : w.toCharArray()) {
            if (p.next[c - 'a'] == null) p.next[c - 'a'] = new TrieNode();
            p = p.next[c - 'a'];
        }
        p.word = w;
    }
    return root;
}
72. Merge k Sorted Lists (Heap / Priority Queue)

Question: Merge k sorted linked lists into one sorted linked list.

Approach:

Use PriorityQueue storing current head nodes of all non-empty lists.

Time: O(N log k) | Space: O(k)
public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode node : lists) if (node != null) pq.add(node);
    ListNode dummy = new ListNode(0), curr = dummy;
    while (!pq.isEmpty()) {
        ListNode top = pq.poll();
        curr.next = top;
        curr = curr.next;
        if (top.next != null) pq.add(top.next);
    }
    return dummy.next;
}
73. Top K Frequent Elements (Heap / Bucket Sort)

Question: Return the k most frequent elements in an array.

Approach:

Count frequencies using HashMap, then use Bucket Sort array indexed by frequency.

Time: O(N) | Space: O(N)
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    for (int n : nums) count.put(n, count.getOrDefault(n, 0) + 1);
    List<Integer>[] bucket = new List[nums.length + 1];
    for (int key : count.keySet()) {
        int freq = count.get(key);
        if (bucket[freq] == null) bucket[freq] = new ArrayList<>();
        bucket[freq].add(key);
    }
    int[] res = new int[k];
    int idx = 0;
    for (int i = bucket.length - 1; i >= 0 && idx < k; i--) {
        if (bucket[i] != null) {
            for (int num : bucket[i]) {
                res[idx++] = num;
                if (idx == k) break;
            }
        }
    }
    return res;
}
74. Find Median from Data Stream (Heap / Design)

Question: Design data structure supporting addNum and findMedian operations.

Approach:

Maintain two heaps: Max-Heap for lower half of numbers, Min-Heap for upper half.

Time: O(log N) addNum, O(1) findMedian | Space: O(N)
class MedianFinder {
    private PriorityQueue<Integer> small = new PriorityQueue<>((a, b) -> b - a); // Max heap
    private PriorityQueue<Integer> large = new PriorityQueue<>(); // Min heap

    public void addNum(int num) {
        small.add(num);
        large.add(small.poll());
        if (small.size() < large.size()) small.add(large.poll());
    }
    public double findMedian() {
        return small.size() > large.size() ? small.peek() : (small.peek() + large.peek()) / 2.0;
    }
}
75. Task Scheduler (Heap / Greedy)

Question: Return minimum CPU intervals needed to execute all tasks given cooling time n.

Approach:

Calculate idle slots based on highest task frequency; fill remaining slots with lower frequency tasks.

Time: O(N) | Space: O(1) auxiliary
public int leastInterval(char[] tasks, int n) {
    int[] freq = new int[26];
    for (char t : tasks) freq[t - 'A']++;
    Arrays.sort(freq);
    int maxFreq = freq[25] - 1;
    int idleSlots = maxFreq * n;
    for (int i = 24; i >= 0 && freq[i] > 0; i--) {
        idleSlots -= Math.min(freq[i], maxFreq);
    }
    return idleSlots > 0 ? tasks.length + idleSlots : tasks.length;
}
